**Hinweise für die Aufnahme:**

1. **Private Daten:** Kunde-Namen, Order-IDs, Store-Names und BL-Consumer-Keys nie zeigen. Am einfachsten mit dem Screenshot-Tool selbst vorher wegschneiden oder mit einem Editor (GIMP, Photoshop, sogar Paint) schwarze Balken drübermalen.
2. **Browser:** Firefox oder Chrome, Fenster ~1440px breit, damit die Layout-Anzeige stimmt (Tailwind-Breakpoints).
3. **Format:** PNG, keine Kompression nötig — GitHub liefert die eh optimiert aus.
4. **Retina/HighDPI:** wenn du auf einem Retina-Display bist, sind die Bilder doppelt so groß pixelmäßig — das ist ok, sieht schärfer aus.

Wenn du weniger machen willst: `01-watchlist.png` + `03-settings-pricing.png` reichen für einen ersten Eindruck. Der Rest ist "nice to have".
